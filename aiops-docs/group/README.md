# Auto206Agent 课题组全局知识库说明

本目录下的 Markdown 会在 **Auto206Agent** 应用启动时被索引到向量库（与 `aiops-docs` 根目录其他文档相同），对话中可通过自然语言提问，助手会调用 `queryInternalDocs` 检索后回答。

## 如何维护

1. **成员信息**：编辑 `members.md`，按表格或列表补充导师、博士生、硕士生等（姓名、角色、邮箱、研究方向、办公室等）。
2. **论文与成果**：编辑 `publications.md`，按会议/期刊、年份、题目、作者、链接填写。
3. **项目与在研工作**：编辑 `projects.md`，写清项目名称、负责人、起止时间、简介与对外链接。

修改保存后需**重启应用**或走你们现有的全量重建索引流程，新内容才会进入检索（若项目已配置监听目录则按项目说明操作）。

## 与会话上传的区别

- **本目录**：全组共享的「全局」文档，所有会话检索时可见（与实现中的 `_kb_scope` 全局文档一致）。
- **界面上传的文件**：绑定当前会话，适合个人材料、组会 PPT、临时论文草稿等；同一 `sessionId` 下多轮对话可继续引用。
